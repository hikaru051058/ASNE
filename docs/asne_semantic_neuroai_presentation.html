Artificial Semantic Neural Evaluation

A compact walkthrough of the hypothesis, tool workflow, implementation shape, and current outcome for a semantic NeuroAI / LLM tooling discussion.

One-line version ASNE compares TRIBE-predicted cortical response signatures across controlled semantic stimuli, then reports which contrasts are separable and interpretable.

Starting point

The hypothesis

Research hypothesis If a frozen neural encoding model predicts cortical-like responses from language/audio, then carefully controlled semantic contrasts should produce distinguishable predicted response patterns.
Operational test Build paired stimulus dictionaries, run each item through TRIBE v2, compare the predicted response signatures, and ask whether held-out examples land on the expected side of the contrast.
Important: this is model-predicted response space, not measured fMRI.2 / 11
Why semantic contrast matters

Semantics as controlled contrast testing

Minimal-pair spirit Many stimuli are paired so the surface form changes less than the semantic relation: expected vs. unexpected, valid vs. invalid cause-effect, consistent vs. contradictory.
Distributional + neuroAI bridge Instead of only asking what an LLM embedding says, ASNE asks what a brain-response prediction model does with the same semantic manipulation.
Tooling angle The project is an example of using LLM-assisted coding to build repeatable evaluation infrastructure around a research idea.
Framing: hypothesis generation and model analysis.3 / 11
What it does

ASNE adds the experiment layer around TRIBE

Stimulus pairControlled text examples for each semantic category.
TTS / eventsText can be converted into audio/event inputs.
TRIBE v2Frozen model predicts cortical response signatures.
Response arraySegments × 20,484 cortical vertices.
AggregationMean, temporal, and HCP-MMP parcel signatures.
ReportAccuracy, margins, failures, and interpretable parcel summaries.

ASNE itself is not the brain model. It is the orchestration, dictionary, scoring, parcellation, temporal-analysis, and reporting layer around the model.

Core repository modules: dictionary, evaluation, roi, temporal, reporting, adapter.4 / 11
How it works

The comparison logic

traditional encoding: response = f(stimulus)
ASNE contrast workflow: response signature → category comparison
optional steering idea: response = f(stimulus, steering_state)
Scoring intuition For each category, ASNE builds a centroid-like predicted response signature from a stimulus dictionary. A held-out example is then scored by similarity to each category signature. Correct top-1 means the expected category ranked first.
The current strongest path is semantic contrast evaluation, not psychological state detection.5 / 11
Implementation shape

What the code is doing

Main components
  • dictionary.py: validates stimulus dictionaries and leakage terms.
  • evaluation.py: computes top-1, top-2, rank, confusion, and failures.
  • roi.py: maps 20,484 vertices into HCP-MMP parcels.
  • tribe_adapter.py: keeps TRIBE access behind a swappable adapter.
  • reporting.py / scripts: produce static summaries and demo reports.
Why this structure matters It separates the research question from the model runner. That makes the same experiment design reusable with mock data, TRIBE outputs, vertex-level scoring, parcel-level scoring, and temporal segment diagnostics.
Mid-level code explanation: data in, adapter call, signatures out, scoring/reporting.6 / 11
Current contrast suite

What was tested

Contrast Question it asks Current status
expected_vs_unexpected Does the event fit the prior context, or violate it? Stable signal
cause_effect_valid_vs_invalid Does the causal relation make sense? Stable / viable
contradiction_vs_consistency Does the sentence conflict with earlier information? Weak after larger evaluation
approach_vs_static Is a motion/arrival relation present? Low priority for text/TTS; likely needs video-native stimuli
The useful contrasts are semantic outcome/anomaly contrasts.7 / 11
Outcome

v0.3-lite result snapshot

Expected vs. unexpected 0.90 Parcel top-1 accuracy on ten held-out examples. Temporal late accuracy was also 0.90.
Cause-effect valid vs. invalid 0.80 Parcel top-1 accuracy. Majority temporal accuracy was 0.70.
Contradiction vs. consistency 0.50 Parcel top-1 accuracy after expansion, so this was deprioritized.
Small eval sets: useful stability checks, not definitive benchmark claims.8 / 11
What changed from prototype to result

The useful finding was narrower than the original ambition

Original broad idea Test whether steering conditions can move predicted cortical response patterns in reproducible, interpretable ways.
Current strongest result The project is strongest as a semantic contrast testing workflow. It can show that some semantic anomaly/outcome contrasts separate in predicted TRIBE response space, especially after parcel aggregation.
This is a productive narrowing, not a failed result.9 / 11
Interpretation boundaries

What ASNE does not show

Not measured brain activity The numbers come from predicted cortical signatures generated by a model.
Not mind reading or emotion detection Contrast labels are experimental categories, not claims about a person.
Not production-ready classification The current benchmark has ten held-out examples per contrast, so it supports direction setting rather than general accuracy claims.
Empirical neuroscience claims would require validation against measured human data.10 / 11
Discussion close

Why this is worth showing

Research value ASNE gives a concrete way to turn semantic contrast design into model-response experiments with reproducible reports, failure cases, and interpretable aggregation.
Next directions
  • Expand the stable semantic anomaly benchmark.
  • Try video-native stimuli for motion and event structure.
  • Compare TRIBE response space with LLM embedding baselines.
  • Return to steering once the semantic evaluation layer is stronger.

Suggested spoken ending: “The interesting part is not that this proves a brain claim. It is that we can build a tool-mediated loop where semantic hypotheses become controlled stimuli, model-predicted response signatures, and inspectable errors.”
